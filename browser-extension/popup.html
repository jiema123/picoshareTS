上传数据说明

当你主动点击上传、网页 HTML、长截图、图片保存或网页链接操作时，扩展会读取你选择的文件、当前页面内容或图片，并发送到你设置的 PicoShare 服务以生成分享链接。保存网页图片时，来源网站会收到读取请求，浏览器可能按该站点规则附带凭据；官方托管服务会处理访问者 IP 和浏览器信息以统计下载次数。API Key 和设置保存在本浏览器扩展存储中；持有分享链接的人可能可以打开对应内容。

密钥保存在本浏览器扩展存储中。首次保存会请求访问你填写的 PicoShare 网站。

常驻网页按钮

在网页右下角显示 PicoShare 小图标，不用每次打开插件菜单。

按住常驻图标可拖动并记忆位置。左键打开菜单：可将整页截图上传为 PNG、选择本地文件上传，或上传当前网页 HTML；右键将清理后的当前网页地址保存为 .txt 分享（会移除查询参数和片段）。首次启用会请求所有网站权限，供常驻图标和长截图使用。

网页右键菜单

网页空白处右键可上传当前网页 HTML；图片上右键可保存图片到 PicoShare。完成后会打开分享链接。

页面 HTML 会以纯文本类型分享，打开链接时显示源码，不会执行网页脚本。
